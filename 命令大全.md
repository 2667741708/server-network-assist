# Server Network Assist 命令大全

本文对应 Server Network Assist `0.5.1`，集中列出安装、管理台、网络借助、Clash/TUN、桌面面板、恢复和开发验证命令。示例中的主机名称和地址需要替换成管理台中的实际值。

## 1. 查看帮助与版本

```bash
server-network-assist --version
server-network-assist --help
server-network-assist-ctl --help
server-network-assist-ctl profile-create --help
server-network-assist-ctl clash-mode --help
```

CLI 默认读取 `/var/lib/server-network-assist`。使用其他数据目录时，把全局参数放在子命令之前：

```bash
server-network-assist-ctl --data ./data --master-key ./data/master.key --json hosts
```

## 2. 安装

### Ubuntu / Linux 源码安装

```bash
git clone https://github.com/2667741708/server-network-assist.git
cd server-network-assist
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install .
```

需要桌面托盘时：

```bash
python -m pip install ".[desktop]"
```

### Windows PowerShell 源码安装

```powershell
git clone https://github.com/2667741708/server-network-assist.git
Set-Location -LiteralPath '.\server-network-assist'
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install '.[desktop]'
```

## 3. 初始化和启动管理台

### 本地测试

```bash
server-network-assist init --data ./data
server-network-assist serve --data ./data --bind 127.0.0.1 --port 9180
```

指定独立密钥文件：

```bash
server-network-assist init --data ./data --master-key ./secrets/master.key
server-network-assist serve --data ./data --master-key ./secrets/master.key --bind 127.0.0.1 --port 9180
```

监听非回环地址时必须指定浏览器看到的精确 HTTPS 来源：

```bash
server-network-assist serve --data ./data --bind 0.0.0.0 --port 9180 --origin https://example.com
```

### systemd 服务

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now server-network-assist.service
sudo systemctl status server-network-assist.service
sudo systemctl restart server-network-assist.service
sudo systemctl stop server-network-assist.service
sudo journalctl -u server-network-assist.service -n 200 --no-pager
```

## 4. 导入 SSH 主机

一个或多个 `--alias` 必须是 OpenSSH 配置中已明确配置的别名：

```bash
server-network-assist import-ssh --data ./data --alias cloud
server-network-assist import-ssh --data ./data --alias cloud --alias c201-4090-wg --group "实验室服务器"
server-network-assist import-ssh --data ./data --config ~/.ssh/config --known-hosts ~/.ssh/known_hosts --alias d408
```

## 5. 查看服务器、客户端与方案

```bash
sudo server-network-assist-ctl hosts
sudo server-network-assist-ctl profiles
sudo server-network-assist-ctl --json hosts
sudo server-network-assist-ctl --json profiles
```

`hosts` 中的角色含义：

- `server:方案名`：该主机是方案的源网服务器。
- `client:方案名`：该主机是方案的借网客户端。
- `unassigned`：主机尚未加入面板管理的借网方案。

## 6. 联网探测与辅助程序

```bash
sudo server-network-assist-ctl probe --host all
sudo server-network-assist-ctl probe --host d408
sudo server-network-assist-ctl --json probe --host d321-titan
sudo server-network-assist-ctl helper-install --host d408
```

`--host` 接受主机显示名称或 ID。

## 7. 创建借网方案

### 一台源网服务器和一台客户端

```bash
sudo server-network-assist-ctl profile-create \
  --name titan-borrow \
  --server c201-5080-wg \
  --client d321-titan \
  --endpoint 10.201.250.20 \
  --preserve-route 10.20.0.0/16
```

### 多客户端

```bash
sudo server-network-assist-ctl profile-create \
  --name lab-borrow \
  --server c201-5080-wg \
  --client d321-titan \
  --client d408 \
  --endpoint 10.201.250.20 \
  --port 51919 \
  --tunnel-cidr 10.213.20.0/24 \
  --preserve-route 10.20.0.0/16 \
  --preserve-route 10.201.250.0/24
```

### 同时共享源机器代理

```bash
sudo server-network-assist-ctl profile-create \
  --name titan-with-proxy \
  --server c201-5080-wg \
  --client d321-titan \
  --endpoint 10.201.250.20 \
  --proxy-mode share \
  --proxy-host 127.0.0.1 \
  --proxy-port 7897
```

创建参数：

| 参数 | 作用 | 默认值 |
| --- | --- | --- |
| `--id` | 自定义方案 ID | 自动生成 |
| `--name` | 方案名称 | 必填 |
| `--server` | 源网服务器名称或 ID | 必填 |
| `--client` | 客户端名称或 ID，可重复 | 至少一个 |
| `--endpoint` | 客户端可访问的源服务器 IPv4/域名 | 必填 |
| `--port` | WireGuard UDP 端口 | `51919` |
| `--tunnel-cidr` | 私有隧道网段 | 自动选择 |
| `--preserve-route` | 必须保留的管理网段，可重复 | 空 |
| `--proxy-mode` | `direct` 或 `share` | `direct` |
| `--proxy-host` | 源机代理监听地址 | `127.0.0.1` |
| `--proxy-port` | 源机 HTTP/mixed 代理端口 | `7897` |
| `--no-maintenance` | 不安装定时维护任务 | 默认启用维护 |

## 8. 启用、退出和删除借网方案

```bash
sudo server-network-assist-ctl profile-enable --profile titan-borrow
sudo server-network-assist-ctl profile-disable --profile titan-borrow
sudo server-network-assist-ctl profile-delete --profile titan-borrow
```

`profile-disable` 是正常的“退出借网并恢复原网络”命令，会恢复该方案记录的路由与代理。应先退出再删除；仍处于启用状态或尚未完成清理的方案不能删除。

## 9. Clash / Mihomo 状态

```bash
sudo server-network-assist-ctl clash-status --host d321-titan
sudo server-network-assist-ctl --json clash-status --host d321-titan
```

## 10. Clash 流量模式

```bash
sudo server-network-assist-ctl clash-mode --host d321-titan --mode rule
sudo server-network-assist-ctl clash-mode --host d321-titan --mode global
sudo server-network-assist-ctl clash-mode --host d321-titan --mode direct
```

## 11. Clash 策略组和节点

先通过 `clash-status` 查看 `groups`、当前节点和候选节点，再执行：

```bash
sudo server-network-assist-ctl clash-proxy-select \
  --host d321-titan \
  --group "🚀 节点选择" \
  --name "香港 A"
```

## 12. 系统代理

```bash
sudo server-network-assist-ctl clash-system-proxy --host d321-titan --value on
sudo server-network-assist-ctl clash-system-proxy --host d321-titan --value off
```

远程系统代理开关支持 Windows 当前 SSH 用户。Ubuntu SSH 会话不能代表已登录的 GNOME 桌面用户修改系统代理，服务器环境应优先使用 TUN。

## 13. TUN

```bash
sudo server-network-assist-ctl clash-tun --host d321-titan --value on
sudo server-network-assist-ctl clash-tun --host d321-titan --value off
```

TUN 切换可能短暂改变目标机路由。执行前应确认 SSH 管理地址包含在保留路由内，并存在可用的恢复路径。

## 14. Clash 规则

```bash
sudo server-network-assist-ctl clash-rule-add \
  --host d321-titan \
  --rule "DOMAIN-SUFFIX,openai.com,🚀 节点选择"

sudo server-network-assist-ctl clash-rule-add \
  --host d321-titan \
  --rule "DOMAIN-SUFFIX,whm12.art,DIRECT"
```

规则会加入当前活动配置顶部。修改前自动创建 `.sna-backup-*`；热加载失败时自动恢复。订阅更新可能重新生成活动配置，长期规则还应加入 Clash Verge Rev 的 Merge/Script 配置。

## 15. 目标机低级恢复命令

正常情况下使用 `profile-disable`。只有管理面板无法工作、并且已经确认方案 ID 时，才在目标 Ubuntu 主机上调用辅助程序：

```bash
sudo /usr/local/sbin/server-network-assist-helper status
sudo /usr/local/sbin/server-network-assist-helper disable PROFILE_ID
ip route
sudo wg show
systemctl list-timers 'server-network-assist-*'
```

不要直接删除辅助程序状态目录；恢复路由需要其中保存的原始状态。

## 18. 常见完整流程

```bash
sudo server-network-assist-ctl probe --host all
sudo server-network-assist-ctl helper-install --host c201-5080-wg
sudo server-network-assist-ctl helper-install --host d321-titan
sudo server-network-assist-ctl profile-create --name titan-borrow --server c201-5080-wg --client d321-titan --endpoint 10.201.250.20 --preserve-route 10.20.0.0/16
sudo server-network-assist-ctl profile-enable --profile titan-borrow
sudo server-network-assist-ctl clash-status --host d321-titan
sudo server-network-assist-ctl clash-mode --host d321-titan --mode rule
sudo server-network-assist-ctl clash-system-proxy --host d321-titan --value on
sudo server-network-assist-ctl profile-disable --profile titan-borrow
```

这一流程最后使用 `profile-disable` 完整退出借网。关闭系统代理、关闭 TUN和退出借网是三个不同操作，应根据目标机器当前使用的接管方式分别执行。
