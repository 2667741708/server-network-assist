# OPS-NET-032：Sol 订阅仪表盘 UI 优化

- 日期：2026-09-17。
- 状态：已完成前端、操作验证和纯静态部署；真实 public 鉴权读取通过。
- 范围：订阅管理 HTML/CSS/JS、本地现成 Tabler UI 资产、cloud 静态允许路径。商业后台和客户端网络代码不改。
- 关联：REQ-NET-031 / TEST-NET-039，继承 REQ-NET-030 与本机网络不修改约束。

## 触发条件和现象

用户要求制定仪表盘优化提示词，并明确使用 Sol 模型重新设计。原页面有重复客户列表、多列宽表和长页面表单，核心管理动作不易扫读。

## 真实证据

提示词已保存于 `docs/SUBSCRIPTION_DASHBOARD_REDESIGN_PROMPTS.md`，包含总提示词、12 个执行点、九项设计系统计划与验收要求。前端实现由独立 gpt-5.6-sol 智能体负责，父智能体负责预制组件资产、测试、部署和审查。当前商业后台 69 项相关回归通过。

## 根因

此前直接使用现有普通 section/form/table 组合，信息分区和运营数据扫读不足；完整后端功能不能代替完整的界面组织。

## 修复方案与实施记录

采用官方 Tabler 1.5.1 已编译资产及官方 page/header/nav/card/table/badge/progress/form/alert 模式，默认视觉，不重新发明主题。版本、源地址、文件 SHA256 和 MIT license 保留在管理 UI 目录，CSS 无外部字体或 CDN 请求。客户管理默认，生成订阅和商业出口独立工作区；六列表格压缩常规信息，完整数据留在详情，重要长值支持换行与区域滚动。服务编辑、地址查看/补发、设备管理、代理启动和源/线路出口设置语义保留。

`scripts/deploy_subscription_admin_redesign.py` 仅预备/写入九份静态文件，按 SHA256 及压缩原长校验，保留备份和失败回滚。预备/执行分开；全过程不重启任何商业控制 API/中继/WireGuard/Mihomo。`scripts/deploy_subscription_admin.py` 将 Tabler 静态资源加入现有 public/WG 路径 allowlist，认证 cookie/Origin/CSRF 代理规则保持。cloud Caddy 已 validate 并 graceful reload，备份 `/etc/caddy/Caddyfile.sna-subscriptions-1789650481232007869`。

## 验证结果

两套完全拦截请求的浏览器 fixture 均通过：`tests/subscription_dashboard_ui_browser.cjs` 验证三工作区导航、筛选、180 天/无限额度与不限速修改、源代理就绪门禁、详情和设备停用/恢复、旧数据锁定及退出清空；`tests/subscription_admin_ui_browser.cjs` 验证生成、完整地址显示、刷新后查看、显式补发、设备上限保护、源/客户线路出口设置、启动源代理和确认凭据清空。模拟操作没有修改真实客户。

1440/1024/390px 无整页水平溢出；桌面和小屏截图审查通过，宽表单独滚动、长值完整换行。过程中发现 Tabler 复选框负 margin 使源选择框被卡片遮挡，已修复优先级及布局；结果地址滚动改为定位具体 textarea，测试等待官方平滑滚动完成后核验视口可见性。后台相关 69 项回归通过。

源端九份静态文件校验发布成功，本机 HTTP 摘要与候选一致，备份 `/home/a/sna-dashboard-sol-20260917/backup-1789651136484585521`。部署前后实际 IPv4 路由、策略规则、后台文件摘要、商业 API 和 Mihomo/WireGuard/中继 timer 的状态、InvocationID/MainPID 一致，没有服务重启。

真实 `https://whm12.art/subscription-admin/` 登录与 Cookie/CSRF 代理验证通过，读取 12 位客户；公开九份文件与发布候选逐字节相同，匿名仪表盘返回 401，商业控制 CLI 读取的客户数与仪表盘相同。验证不修改客户服务。浏览器截图为 fixture，不是实际客户截图。

## 风险与回滚

### 同日补充：地址就近查看

用户反馈客户行操作与确认/结果区域距离过远。查看与补发改为当前视口内的原生 modal dialog，沿用 Tabler 标题、按钮、表单与背景角色；生成结果也在同一地址窗口显示。点击立即打开确认，查看成功直接展示地址，不等待客户列表刷新。关闭按钮、取消或 Esc 清空凭据与地址并保留原页面位置；窗口打开时暂停周期性列表重绘，正在请求时禁止 Esc 中断确认。

两套浏览器 fixture 再次通过，新增 1440/1024/390px 的弹窗视口边界、打开不跳页、关闭保留查询位置和 Esc 凭据清理检查。纯静态更新备份 `/home/a/sna-dashboard-sol-20260917/backup-1789652161104674122`，路由/规则、后台摘要及服务指纹保持。真实 public 登录读取12客户和九份文件一致再次通过；没有修改真实订阅或网络服务。

静态资产需要同一版本协同发布，旧页面可强制刷新重新读取。回滚仅恢复本轮源端九份静态文件备份与 Caddy 允许路径备份；不覆盖 SQLite、不重启网络服务。保留所有原客户套餐、设备、订阅地址、账期和用量。
