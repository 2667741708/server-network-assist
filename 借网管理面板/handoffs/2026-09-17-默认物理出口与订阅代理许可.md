# OPS-NET-024：默认物理出口与订阅代理许可

## 已实现

新订阅始终默认物理宽带。源网登记保存物理网卡/网关和可选 proxy_interface（默认Meta），生成时只有 proxy_source_ids / CLI --proxy-source 明确选中的源网使用代理。源端服务运行不改变其他授权。

源端 commercial_proxy 读取 main 表物理默认路由，排除 tun/WG/dummy，拒绝同优先级出口歧义；proxy_status 同时检查 mihomo.service 和实际 UP 的 tun 接口。授权选择/变更检查就绪，代理租约/续租检查就绪，中继 API 对未就绪代理授权不下发策略，客户端节点 available=false。新 metadata 不传给严格旧中继；默认代理响应仍兼容，physical 仅传两项支持的路由字段。

源机控制仅启动已有 mihomo.service：隔离 Python 的 root-owned /usr/local/sbin/sna-commercial-proxy，只接受一个固定 start 参数；sudoers 仅 a 用户执行该固定命令，不允许任意 unit、接口参数、配置写入或密码传输。网页动作要求管理员、当前CSRF和fresh认证。现网商业端在4090，其他远程源机未接入代理状态时拒绝代理授权。

## 部署及迁移

25 项应用、中继模块和 UI 文件部署并验证，备份 /var/backups/sna-egress-deploy-20260917-default。控制 helper 的备份 /var/backups/sna-commercial-proxy-control-20260917。

源网默认 enp4s0 / 10.20.32.1；商业10.20.32.13:51910的9条旧授权调整 physical。这些授权原有公共IPv4 DNS和IPv4 AllowedIPs不变，保留已有租约；没有覆盖其他旧入口。执行前保存字段快照和原主路由/规则，并设置180秒独立恢复 timer。验收成功后取消 timer。

字段快照：/home/a/.local/share/server-network-assist-commercial/physical-default-20260917.json（0600）；网络基线 /var/backups/sna-default-egress-baseline-20260917.json（0600）。恢复脚本只恢复本轮源网configuration和授权egress字段，随后同步中继，不替换整个动态数据库。

## 使用及限制

[实际管理入口](https://whm12.art/subscription-admin/subscriptions.html)：正常生成订阅无需选出口；需要代理时先启动4090 Mihomo/TUN，再为新订阅勾选代理，或修改指定旧授权。一般手动授权切换撤销旧租约，客户需重新入网。进程/TUN就绪不保证机场节点与所有目标站点可用。
