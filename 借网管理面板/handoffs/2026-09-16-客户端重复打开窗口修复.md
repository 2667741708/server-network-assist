# 客户端重复打开窗口修复

## 实际原因

本机现有进程为 Python 网页后台，记录 PID 14984、端口 55324，健康接口识别为 server-network-assist-client 0.7.0。没有原生桌面 EXE 进程，因此此旧后台没有桌面窗口或托盘图标。旧 EXE 发现它运行后只提示“已经启动”，没有打开网页面板。

## 修复行为

- 新版 EXE 重复打开会认证已有后台，并请求显示、恢复其桌面窗口。
- 已运行的旧原生桌面版本没有显示接口时，只恢复匹配后台 PID、窗口标题和 Windows Forms 类名的窗口。
- 已运行的旧 Python 网页后台没有托盘时，在默认浏览器打开现有面板，不停止或重建后台。
- 后台尚在启动或恢复、所有权锁不可取得时，仅重试打开并提示等待；不执行第二次启动或网络恢复。
- 显示接口需要本机 Host、客户端令牌和明确的同源 Origin。仅显示窗口，不取得网络操作锁。
- Guardian 的进程、EXE 路径、令牌和严格 PID 检查保持独立；旧健康接口兼容仅授权打开界面，不授权清理网络。

只打开已有面板的命令：

```powershell
.\ServerNetworkAssistClient.exe --show
```

无后台时 `--show` 不启动客户服务、不恢复网络。源码环境的等价入口是 `python scripts/show_client_ui.py`。
