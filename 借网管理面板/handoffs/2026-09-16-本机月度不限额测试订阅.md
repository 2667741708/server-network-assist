## 不限速实现及审查修复

CLI 明确使用 --unlimited-speed，将上传、下载上限置 null。服务 API 保留 null，不替换为虚假的限速数字。Linux 中继不为此客户创建下载分类或上传限速器；共享中继默认分类原有 100 Gbit/s 工程上限保留，不意味着真实无限带宽。计量、租约撤销、到期和客户隔离继续生效。

独立审查发现并修复：限速转不限速的历史 TC 删除失败后重试遗漏，速度显示的 bit/s 与 byte/s 混淆，以及恢复中 peer 的 TC 编号碰撞。恢复记录中的历史规则保留到删除成功或只读 JSON 查询证明不存在；清理未完成不能将不限速策略标为 active；恢复中的编号不会分配给另一客户。

服务端仅更新 ClientStore、管理员 CLI、服务 API 和 root 中继模块，更新前备份。最后中继模块备份目录 `/var/lib/server-network-assist-relay/unlimited-source-backup-1789573970914478083`。
