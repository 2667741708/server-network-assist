# OPS-NET-013 / ERR-NET-013：热点订阅与实际源网管理入口

- 日期：2026-09-17。
- 状态：已实现、已部署、有限运行时验证；真实本机开户及入网未执行。
- 范围：Windows 客户端、4090 商业源网管理 UI、cloud Caddy 的订阅管理路径。
- 关联：REQ-NET-013、TEST-NET-021；继承 REQ-NET-002/003/004/007。

## 触发条件和现象

用户授权保留热点或普通公网网络时读取订阅并检测源网，指出打开的云端管理器没有订阅生成入口。此前只给出源码中存在的商业页面位置，未确认部署版本，是错误入口判断。

## 真实证据

Reliable SSH 验证 cloud 为 VM-0-12-ubuntu、4090 为 a-MS-7E06。4090 sna-commercial 服务监听 9182，源网 Endpoint 为 10.20.32.13:51910，数据库为 `/home/a/.local/share/server-network-assist-commercial/data/commercial-service.sqlite3`。其已安装后端有商业管理 API，旧 UI 没有签发页面。cloud `/network-assist/` 为独立协作台/数据库，不能在该数据库签发并当作 4090 源网授权。

cloud Caddy 已经有 HTTPS `/client/v1/*` 到 `10.201.250.10:9182` 的转发；cloud 经该 WG 地址的实际 TCP 9182 成功，直连校园地址超时，二者分别记录。本机物理网络为热点 WLAN 192.168.43.140；直连公网域名 TLS 重置，显式使用已启用的本地 CONNECT 代理后 API/页面成功。没有更改该代理或其绕过列表。

源网初始密码已失效，当前密钥通过本机哈希和真实服务登录核验；不记录任何凭据。网页再次验证沿用既有 `/api/login` 接口，使用返回的新 CSRF 和其既有五分钟签发授权，不增加任何后端免验证分支。

## 根因

读取订阅与真正借网共用了严格校园校验；订阅读取应允许现有公网路径，而真正建立客户公网出口仍需接入与个人网络保护。订阅页只存在于未部署的 frontend WIP，错误打开 cloud 协作台也不能获得正确源网授权。标准 urllib ProxyHandler 遵循全局域名绕过配置，令公网订阅仍直连失败。

## 修复方案与实施记录

- `client_lan_transport.py` 增加订阅路径选择及仅用于公网 HTTPS 的现有代理 CONNECT；私网不代理，保持接口与 DNS 绑定。先无凭据 TCP 预选直连路径，POST 后不重试到第二网卡；目标 TLS 和同源跳转校验保持。
- `client_online.py` 将控制请求从 campus_opener 改为 subscription_opener。`client.py` 的只读检查不再因热点提前返回，获取订阅并分别显示源网检查；4090 已知管理 TCP 9182 单独探测，UDP 是否可用留待手动入网的近期握手验证。其他节点仅解析，不猜测其 TCP 服务。真正借网、个人账号与退网保护未放宽。
- `subscription_admin_ui/` 是签发页规范源码，`scripts/build_frontend.py` 在 Angular 构建复制后带入，避免后续构建丢失。`ui/subscriptions.*` 为发布副本。表单仅登录、查看源网/客户、签发订阅与退出；不会自动生成客户，长值可换行、滚动和选择复制。
- `scripts/deploy_subscription_admin.py` 仅部署三个静态文件和显眼的管理入口，不发布其他 WIP、不重启源网后端或 relay。cloud Caddy 增加限定页面/API 的 `/subscription-admin/` 转发；在 Origin 校验通过后才转换到后台已允许的校园 origin。签发仍需现有管理员会话和 CSRF。Cookie 在代理层重命名、限定路径，避免与 cloud 的 panel_session 混用。已修正并复核 Caddy 指令排序，非允许 Origin POST 在进入代理前返回 403。
- 源网 UI 原始备份：`/home/a/.local/share/sna-subscription-ui-20260917/backup-1789608632019403860`。cloud 原始 Caddy：`/etc/caddy/Caddyfile.sna-subscriptions-1789608645692574537`；原始 cloud index：`/tmp/sna-subscription-admin-20260917/original-cloud-index`。Caddy 使用验证后的候选配置和 graceful reload，不重启其他服务。

## 使用方式

公网签发入口：`https://whm12.art/subscription-admin/subscriptions.html`。操作员已有 WG 管理入口：`http://10.201.250.1:9180/subscription-admin/subscriptions.html`，仅经既有 WG 管理网络可达，不是公网 HTTP 入口。校园直连：`http://10.20.32.13:9182/subscriptions.html`。

使用源网管理端账号 admin 和当前密码或登录密钥；选客户名称、源网、流量与上下行速度，保留默认 `https://whm12.art`，再次输入源网管理凭据并手动生成。将含一次性 #enroll 片段的完整地址粘贴到客户软件；不要把私有校园 IP 地址当作公网入口。客户端在热点下可先读订阅，再点“检查订阅与源网”。单网卡连接热点没有同时接入开放校园 SSID，校园源网不通时不能凭订阅成功声称已入网。
