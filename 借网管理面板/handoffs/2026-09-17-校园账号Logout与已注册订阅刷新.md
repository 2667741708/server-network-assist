# OPS-NET-015 / ERR-NET-015：校园账号 Logout 与已注册订阅刷新

- 日期：2026-09-17。
- 关联：REQ-NET-015、TEST-NET-023；继承 REQ-NET-003/007/008/013。
- 状态：实现、隔离测试、只读实际状态核验、EXE 静态核验与本机只复制安装完成。

## 现象、证据与根因

校园连接下截图显示套餐和授权源网，但重复读取地址得到 400。解码错误为“开户令牌无效、已使用或已过期”。源网通过 Reliable SSH lan 路由只读查询确认该客户令牌已使用、有启用设备、尚无租约，不记录客户凭据。实际校园源网 10.20.32.13:9182 物理绑定 TCP 可达；本机只读校园认证 GET 返回 online。重复一次性开户不是刷新订阅，个人校园账号在线也会触发既有入网保护，不能将此归因于 Wi-Fi 私网无法连接。

旧后台会被新快捷方式复用，复制新版不等于正在运行新版。安装不终止旧进程，用户需完全退出旧客户端后再打开。

## 实施

`client_online.py` 将 HTTP JSON 错误解码为中文。已注册 UI 执行现有身份的签名刷新，停止重复 enrollment POST；同地址摘要的新记录支持幂等刷新，旧记录或换地址不覆盖已保存私钥。保持一次性开户、设备限额及请求签名。

`client_campus.py` 采用仓库 `ysunetlogin_openwrt/netlogin.py` 的 auth1 当前会话 Logout 协议：读取 session/cookie 和当前账号状态，再 POST `/eportal/network/offline`。复用客户端严格验证 TLS、固定认证服务与物理接口绑定；不采用旧 HTTP 降级或全账号踢设备流程。只注销当前会话，不上传个人账号密码，诊断结果不包含 session/cookie。

新增手动 `/api/network/campus-logout` 和按钮，保持既有本机令牌与 Origin 保护，只有显式 confirmed 才执行。仍在入网、待恢复、账号状态未知或网卡发生变化时拒绝；成功响应后必须再验证 offline。已下线不重复 POST。Logout 不切换 Wi-Fi、不改变路由/DNS/代理、不自动借网；个人在线时提示用户手动 Logout。

按用户追加要求收紧 UI：无顶部版本横幅，无新增校园账号说明卡片；仅保留“校园账号 Logout · 保持 Wi-Fi”按钮及操作后的状态。订阅说明一句，开放无线说明放在折叠帮助内，版本标记也在折叠帮助。长名称、SSID 和错误保持换行及滚动。
