# 网络管理面板设计约束

## REQ-NET-002：校园组网互通是借网、代理和 TUN 的硬约束

任何已确认处于同一校园组网、且校园基础网络允许互访的机器，必须在借网前后持续保持双向访问。范围包括同一有线子网、校园 Wi-Fi 到有线网络，以及已确认可路由互通的校园跨子网。不能只依靠 SSID、同一网段或 VPN 的开关判断校园接入。

1. **内网走内网，公网才借源网出口。** 校园主机、原网关、校园 DNS/认证服务、源网订阅入口、管理端口和跳板地址保持原有可达路径。不同子网通过原校园网关；已有专用管理隧道的更具体路由保持。
2. **必须同时保护去程和回程。** 从校园原网卡进入的 SSH、RDP、Web、API 等连接，回包不能被借网或 Clash TUN 改送到源机。管理网段必须验证内层路由和外层 WireGuard Endpoint，外层入口不能递归进入正被切换的客户出口。
3. **全生命周期保持。** 借网开启、退网、切换源机、订阅续租/到期/撤销、Clash 普通代理/TUN/规则/全局模式切换、自动维护、重连、客户端软件重启和开机恢复均需满足互通要求。软件重启指重启客户端后台进程，不是重启操作系统；两项分别记录验收，不能相互替代。
4. **仅清理自己拥有的状态。** 退网停止专用客户隧道及依附它的 TUN，撤销自己增加的路由、DNS 和服务状态；不能停用独立跳板、删除管理 VPN、覆盖其他机器或用户新配置。
5. **变更前采集基线，失败可回退。** 记录 IP、网关、实际接口、策略路由、DNS、管理入口及关键服务端口。检查冲突；对远程变更预设不依赖该连接的回退机制。
6. **面板展示真实结果。** 展示源机、客户机、校园访问路径、管理入口路径、测试时间、服务端口结果和故障原因。SSH 请求超时要区分局域网直连、跳板和 cloud 中继，不得直接声称机器掉线或局域网路由错误。
7. **验收实际服务。** 除 route get 和 ping 外，至少验证关键机器双向 TCP 服务连接；借网与退网后重复验证。未执行的机器、端口、平台、开机场景明确标记“未验证”，不得以一个节点通过代替全部组网通过。
8. **跨平台分别实现。** Windows 与 Ubuntu 均需保护校园访问，不把 Linux 路由命令直接用于 Windows。物理网络/VLAN/无线客户端隔离造成的基础不可达应报告，不通过借网伪装为校园互通。

## REQ-NET-003：本机不再作为网络变更测试机

2026-09-16 用户明确禁止调整操作员本机网络配置，后续借网、路由、DNS、代理、Clash/TUN 和客户端重启的网络验收仅在明确指定的服务器上执行。不得在本机安装新网络服务、连接测试订阅或自动套用兼容配置；允许必要的只读排查。需要本机网络变更时，必须由用户另行明确授权，不能沿用早先的测试授权。

## REQ-NET-023：商业物理出口与源端代理策略隔离

物理客户只匹配其来源 /32 和专用入接口，不替换主默认路由或源机自己的代理/TUN。源端代理停用不应阻断已配置物理出口的客户自主代理；物理失效必须终止，不暗中回落到源端 TUN。源端配置与客户策略分离；迁移已有授权显式撤销旧租约，使 DNS随重新入网更新。外来规则/表冲突拒绝覆盖，退网仅删除明确 owned 项。默认策略响应兼容旧中继，未实现的 Windows源端和IPv6不得假报支持。

## REQ-NET-024：物理出口默认，源端代理按订阅授权

新签发订阅和用户 CLI 创建线路默认 physical。源网代理进程与客户代理授权分离：启动 Mihomo 不影响物理客户，仅显式选择的订阅使用 source_proxy。代理授权、租约/续租及中继转发必须检查实际源机服务和 TUN 就绪；未接入远程状态的源机拒绝代理授权，不能借用 4090 状态。不可用节点如实显示，下一次中继同步去除转发，不静默变成其他出口。网页启动仅经 root-owned、isolated Python 的固定 helper 和固定 sudoers 参数启动已有 mihomo.service；禁止任意服务、命令、密码参数或配置写入。新策略不得调整操作员本机网络。批量迁移保留租约仅限 DNS/IPv4 客户契约不变且有独立回退及实际校园 TCP 验收。

## REQ-NET-004：租约签发不等于借网成功

订阅可下载、租约可签发、隧道服务 active 都不能单独认定“已连接”。至少确认对应源机公钥的近期 WireGuard 握手；未完成则撤销本次新建客户隧道并释放租约，不留下抢占公网的失效路由。若清理失败，必须报告“回退未完成”，不得声称原网络已恢复。握手成功仍不等于所有公网网站可用，HTTPS 与校园服务继续分别验收。

## 实现与验收入口

## 客户原生窗口与个人网络优先

客户始终提供显式“退出组网”按钮和 `--leave-network` 命令，退出可保留窗口。仅清理客户拥有的路由、隧道、DNS及代理/Clash字段，不覆盖用户后续变更，不清理管理隧道。关闭窗口意味着恢复并退出，最小化继续运行在通知区。

接入丢失、物理地址或任一IPv4/IPv6默认出口改变必须显示提醒并自动退网；热点和个人校园账号网络优先，不自动重新借网。恢复失败须可见、持续重试，并禁止续租/重新配置。校园服务须经物理接入验证，不仅按SSID字符串判断；未经配置的IPv6出口保守拒绝。普通纯享入网不按IPv4前缀拒绝候选，任意前缀验证实际源网路径；启动/添加/切换订阅自动只读查询，查询不受入网资格门槛影响，不注销、不申请租约、不改变网络、不自动入网，TCP可达不能冒充UDP或公网成功。

个人登录按钮先恢复再打开认证页；外部个人认证成功触发退网。外部仅打开页面即退出、真实热点、其他厂商TUN和Ubuntu等同保护仍是待实现或验收的要求，不得隐藏在通过结论中。范围见[REQ-NET-007](requirements_traceability.md)及[Titan验收](handoffs/2026-09-16-Titan退网安全验收.md)。
