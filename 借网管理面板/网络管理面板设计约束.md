# 网络管理面板设计约束

日期：2026-09-16。适用于管理面板、CLI、客户版、源端中继、Windows/Ubuntu 安装与自动维护流程。此文是必须满足的设计及验收要求；具体部署完成情况以实施记录为准。

## REQ-NET-002：校园网直连与管理组网并列保留

1. 同校园局域网内原本可互访的服务器必须继续可互访。优先使用校园 IP 直接连接，不依赖云端、WireGuard、借网节点或代理运行。
2. 校园内不同子网也属于保护范围：保留原网关、已有静态路由和策略路由的选择逻辑及入站连接回程。不能仅保护客户端自身的 /24，不能以 SSID 相同或不同判断互访能力。校园网原有隔离策略不由本项目绕过；验收基线是原本允许的访问。
3. 同一管理 WireGuard 组网的机器也必须能通过组网 IP 连接。校园网直连与 WG 访问是并列路径；不能以“WG 能访问”掩盖校园网访问失败，也不能以“校园网能访问”掩盖 WG 失败。
4. 客户借网仅改变被授权的公网出口。保留管理 WG、其他既有组网、校园公开地址网段、校园认证与 DNS 所需路径。客户数据隧道不自动承担管理组网功能；两个客户地址能否互访需显式授权，不默认开启商业客户互访。
5. 系统代理例外、Clash DIRECT 规则、TUN 排除、WireGuard AllowedIPs、路由与防火墙均须遵守此约束；应用代理正常不能替代系统路由验证。
6. 禁止在借网、退网、续租、切换源机、自动修复、升级和清理旧配置时删除或停用管理组网。删除前必须核实接口、路由、服务和规则所有者。

## REQ-NET-003：管理入口和回程保护

1. 必须同时保护管理隧道内层地址与外层 Endpoint（IP、端口及传输协议）、SSH 跳板、控制服务和订阅续租入口。仅检查管理网段的路由不足以验收。
2. 管理入口保持切换前已验证的可用路径。不能未经验证将其改经客户代理、TUN 或新借网源；“保护路径”允许专用管理中继，不强制一定走物理网卡。
3. 禁止入口递归：管理隧道外层不能依赖同一管理隧道；借网隧道外层不能被自己的公网路由接管。域名入口需考虑解析结果变化，重新核对所有实际使用的地址。
4. 应记录入口原路由及配置所有者，写入持久配置，保护回程。新增规则只由本项目按所有权撤销；退网不破坏校园直连及管理连接。
5. 必须检查代理/TUN 是否接管管理入口的 UDP/TCP，不能以浏览器 HTTPS 成功推断 WireGuard UDP 可用。

## 面板及验收约束

- 分别展示校园 IP 直连、管理 WG IP 访问、外层管理 Endpoint 路径、公网借网状态及回程路径；未知、失败、过期必须显式显示，不合并为单个“在线”。当前面板仅具备部分路径诊断，完整展示仍待实现。
- 变更前后分别验证源机与客户机双向校园 TCP 服务、跨子网回程、管理 WG 实际握手及 SSH、完整跳板链、公网出口。服务 active 或单次 ping 不能替代这些检查。
- 测试端口以实际监听配置为准。当前 d408 RDP 为 3389、5080 RDP 为 3390，不能把未监听端口误报为路由故障。
- 变更导致任一原本可用的管理或校园路径失败时，停止后续清理并恢复该路径；验收包含退网、再次借网和重启。未执行项必须保留为待验证。
