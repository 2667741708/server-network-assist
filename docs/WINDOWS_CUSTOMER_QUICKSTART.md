# Windows 纯享入网：订阅、出口与通知

## 安装与流量

使用 **20260917-offline-all-deps 完整离线安装包**，适用 Windows 10/11 x64：

1. 完整解压 ZIP，不要只取出 EXE 或直接在压缩包中运行。
2. 双击 `Install.exe`，选择程序目录；只有勾选“允许创建桌面快捷方式”才会创建。
3. 点击“一键安装”。包内包含官方 WireGuard x64 MSI 和 WebView2 x64 完整离线安装器；缺少时允许 Windows 管理员授权。无需联网下载，无需安装 Python。
4. 若组件要求重启，保存工作并手动重启，再运行 `Install.exe` 复查；不会强制重启。
5. 完成后打开“纯享入网”，添加订阅、选择节点，手动开始入网。

客户端所需 Python、pythonnet、运行库 DLL 和本地 UI 已冻结在 EXE 中；使用 Windows 内置 .NET Framework 4.x。此包不适用于 x86 或 ARM64。安装向导不启动客户隧道、不自动入网、不设置开机入网；WireGuard 官方安装会安装其管理服务和驱动。

新用户的私有配置默认位于 `%LOCALAPPDATA%\PureNetworkClient\data`，已有安装版目录优先；若尚无安装版身份且当前用户标准便携版配置存在，优先沿用并在窗口显示。程序目录可选择，升级不覆盖订阅。其他自定义目录可通过“导入旧版订阅”显式导入，导入不会自动选择或连接。

`WinError 2` 表示指定程序或文件不存在，单凭编号无法断定具体文件。新版在个人校园账号处理、租约请求和隧道安装前检查 `wireguard.exe` 与 `wg.exe`；缺少时要求先运行安装程序，保留已保存订阅，无需重新兑换。

界面新增今日流量、当前订阅在本机的累计流量、实时下载和上传速度。累计从首次测量开始，不能补算旧版历史；以此客户端的 WireGuard 隧道计数为来源，约 2 秒采样、5 秒刷新，不包含校园内网直连或绕开隧道的应用流量。套餐限速单独显示，额度扣费以服务端为准。

## 新电脑接入

1. 管理员打开 https://whm12.art/subscription-admin/subscriptions.html ，为这台电脑单独创建客户及订阅，选择允许的源机、流量、速度和期限，复制一次性开户地址。
2. 默认使用源机物理宽带。需要源机代理时，显式勾选该订阅的源代理授权，并确认源机 Mihomo/TUN 就绪。启动源机代理本身不会改变已有物理订阅。
3. 在客户电脑运行 **纯享入网** Windows EXE，允许 UAC 管理员授权，并安装/使用 WireGuard 所需组件。当前 EXE 需要管理员运行；普通权限直接输入订阅不能创建系统隧道。
4. 连接能够实际访问源机的校园 Wi-Fi 或校园有线网络。SSID 含 iYanDa 只是线索；无线隔离、ACL、端口不可达仍会导致无法接入。当前 4090 入口为 `10.20.32.13:9182`，隧道 Endpoint 为 `10.20.32.13:51910/UDP`。
5. 在“添加订阅”粘贴管理员提供的完整订阅网址或 `PURE1-` 开头的订阅码，点击“添加订阅”。不需要在浏览器打开地址，也不需要填写校园网账号。查看源网节点和套餐后，选择节点，点击“开始入网”。添加订阅不会自动入网。
6. 客户只能控制自己的入网和退网，不能使用商业管理权限。不要向客户分发管理密钥；不要复用另一台设备已经兑换的一次性开户地址。已绑定设备通过“刷新已添加订阅”读取数据。

## 物理出口与代理

校园私网保持原校园路径；公网通过客户专用隧道到获授权的源机。

- `physical`：源机物理宽带出口。客户可以使用自己的 Clash 订阅和系统代理；规则匹配交给客户自己的 Clash。源机运行代理不会自动赋予该客户源代理权限。
- `source_proxy`：源机代理出口，需要单独授权及实际源代理就绪。授权和客户端自己的机场订阅是两种配置。

“系统代理开启”不等于所有应用都走代理：是否采用系统代理或应用自身代理取决于应用。TUN 是另一种接管方式；不得仅凭系统代理开关判断应用的实际流量路径。

## 关闭通知

在客户端展开 **通知设置**，关闭 **桌面弹窗通知**；也可以在托盘菜单取消勾选同名选项。设置保存到当前客户端数据目录的 `client-preferences.json`，重新打开仍保留，不改变网络、源网权限或 Clash 订阅。

关闭后不发送托盘弹窗。接入断开、网络切换、恢复失败等错误仍显示客户端状态，同类错误一分钟内不重复打开窗口；事件及接入保护继续运行。

## 多订阅列表、切换与移除

纯享入网在主页面显示“我的订阅”，列表显示订阅名称、服务、客户编号、添加日期和当前选中标记，长列表可滚动。纯享入网 Next 是独立应用，本教程及本次网址/订阅码改造只针对纯享入网。

- **添加**：填写可选名称和新开户地址，点击“添加订阅”。独立保存，保留原身份；正在入网时添加备用订阅不覆盖或断开当前连接。
- **更换**：点击目标项“切换到此订阅”，确认后先恢复当前网络，再选中目标身份。原订阅保留，随后手动开始入网。恢复失败则不切换。
- **移除**：点击指定项“移除”。移除备用项不影响当前连接；移除当前项先退网并恢复。移除是删除本机保存身份，不等于取消服务端套餐或退款。再次绑定需要新的开户地址。
- **历史导入**：点击“导入旧版订阅”，扫描同一 Windows 用户的已有身份文件，去重保存，不切换或连接。已删除的身份或服务端撤销的设备不能保证恢复使用。旧静态隧道不会因此重新启用。

订阅列表保存在私有数据目录的 `customer-online-subscriptions.json`；私钥和一次性令牌不会返回页面。重新启动保留列表，移除项不会自动重新导入。首次更新保留旧当前订阅。

## 完整订阅网址和订阅码

两种输入使用同一开户流程和接入保护。`PURE1-` 是版本化 Base64URL 封装，包含入口地址和一次性令牌，不是加密或管理密钥。不要公开或提交真实订阅码。转换不会续期、增加额度或解除设备绑定；同一设备重复添加同一网址/对应订阅码会复用已保存身份，不重复兑换令牌。

管理员可以将现有完整开户链接保存到受保护的文本文件，然后离线转换：

```powershell
python scripts/convert_subscription_code.py --input enrollment-private.txt --output subscription-code-private.txt
```

输出文件与原地址同样敏感，应放在只有管理员可访问的目录。本次未修改或部署商业管理网页，管理端原有网址仍可直接使用。随机令牌本身不包含入口信息，不能当作 `PURE1-` 订阅码使用。

客户端注册后保存设备身份及原令牌的摘要，不保存原始一次性令牌，因此不能从客户端摘要还原完整开户链接；历史列表展示已保存身份，原始地址需从管理端存档查看。已兑换地址不能直接发给另一台电脑使用。

## 退出与升级

点击 **退出入网 · 恢复原网络**，保留软件和订阅；关闭程序也会执行恢复。切换热点、断开校园接入或使用个人校园账号时，按接入保护退出。原网络恢复失败应重试退出，不能按界面隐藏判断已恢复。

更新程序可以只复制新 EXE 并更新快捷方式，保留旧程序当前连接。随后由用户退出旧程序、确认恢复完成，再打开新版。重复启动不会把正在运行的旧版热更新为新版。
