# 使用手册

## 1. 登录与安全

使用初始化生成的管理员密码或恢复密钥登录。高风险写操作需要再次输入管理员密码，验证窗口为 5 分钟。生产环境配置 HTTPS 后，可以在安全设置中注册 WebAuthn 通行密钥。

## 2. 添加凭据

在“主机与凭据”底部填写名称、类型和密钥内容。凭据使用 `master.key` 加密后写入 SQLite，列表接口只返回标识、名称和类型。

优先使用专用 SSH 私钥和权限受限的远端账号。不要复用个人主密钥。

## 3. 添加主机与跳板

填写地址、SSH 端口、账号、凭据和可选跳板。首次保存后点击“读取指纹”，在服务器控制台或其他可信渠道执行 `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub`，核对 SHA-256 指纹，再保存公钥。

跳板链会逐层应用相同的指纹验证，最多 5 层；检测到循环会拒绝保存。

## 4. 连通性探测

网络页的四个状态含义：

- SSH：管理台能按照保存的路径登录
- DNS：远端能解析公网探测域名
- 公网：远端 HTTPS 请求返回 200/204
- 辅助程序：网络借助 helper 已安装且可由限定 sudo 规则运行

探测是只读操作，不修改路由、DNS 或防火墙。

## 5. 网页终端

选择允许终端的主机后连接。浏览器先申请 30 秒一次性票据，再建立同源 WebSocket。勾选 tmux 会连接到 `network-assist-admin` 会话；未安装 tmux 时请不要勾选。

关闭页面不会自动结束持久 tmux 会话。撤销登录设备、修改主机路径或禁用终端会关闭对应 WebSocket。

## 6. 服务器 Codex 对话

主机状态探测会同时检查远端是否能执行 `codex --version`。在总览点击“打开 Codex”，或进入“Codex 对话”页选择服务器，即可创建独立会话。管理台通过原有 SSH 指纹锁定路径运行远端 `codex exec --json`，后续消息使用 Codex 返回的会话编号继续上下文。

远端服务器必须已经安装 Codex CLI，并由该 SSH 账号完成登录。管理台不会复制 OpenAI 登录信息。默认使用 `workspace-write` 沙箱，也可由 API 创建只读会话；不支持关闭沙箱。消息正文保存在管理台的 `console.sqlite3`，删除会话会同时删除本地消息记录，但不会删除远端 Codex 自己保留的会话文件。

发送消息、新建、停止和删除会话均属于高风险操作，需要管理员密码在最近 5 分钟内验证。服务重启时，正在运行的回复会标记为中止，不会伪报成功。

## 7. 网络借助

详细过程见 [NETWORK_ASSIST.md](NETWORK_ASSIST.md)。核心操作是：探测 → 安装 helper → 新建方案 → 重新验证 → 启用 → 复检 → 需要时断开。

“断开并恢复原网络”会关闭 WireGuard 接口、删除为 SSH 控制面添加的临时路由，并恢复转发状态；不会替你登录校园网或连接热点，这些仍由服务器原来的网络工具负责。

## 8. 审计

审计页面记录动作、目标、时间和来源地址。密码、私钥和完整配置字段会被过滤。运维截图仍可能包含内部地址和主机名，发布前请手工脱敏。
