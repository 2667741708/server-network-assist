# 纯享入网客户端 UI 优化提示词清单

## 总提示词

你是 gpt-5.6-sol 前端实现智能体。改造现有“纯享入网”客户端，使用项目已固定并本地打包的 Framework7 iOS UI，复用 Navbar、List/Radio、Card、Button、Accordion、Dialog、Toggle 等已开发组件，不能自行发明视觉主题或引入联网 CDN。这是付费订阅客户端，不是商业服务端，不是“纯享入网 Next”，不要求客户填写校园账号。

只改 client_ui 的 HTML/CSS 及确有必要的展示 JavaScript。保留所有现有 DOM ID、API、令牌认证、纯网址/订阅码输入、多个订阅、手动源网选择、显式退网、恢复提示、托盘窗口桥接及通知开关。不得改网络后端、接入保护、路由、DNS、代理、TUN、订阅存储或自动连接行为。不要把未知状态伪装成已连接或不限额。

## 可逐项执行的提示词

1. **审查现状**：找出纵向长页面、主操作离状态/节点太远、添加订阅与历史列表割裂、次要帮助抢占空间等问题。用现有组件解决，不能移除核心能力。
2. **固定现成 UI**：沿用 Framework7 iOS 默认组件、系统字体、色彩角色、边框与交互状态；清理重复的自定义视觉覆盖，仅保留桌面尺寸和中文可读性适配。不得虚构设计师或评分。
3. **首屏添加订阅**：添加订阅仍在页面最上方，不需要先展开设置。网址和 PURE1- 订阅码清楚说明，名字可选，粘贴完整输入可读取；提交成功清空敏感输入。
4. **清晰主任务**：状态、接入条件、当前订阅、源网单选、开始和退出形成紧凑连接区。状态和主操作可同时看懂，日常界面只保留一处开始和一处退出。
5. **订阅管理**：保留已添加列表、选中标识、切换、移除、刷新和旧版导入；列表折叠或单独区域，切换确认清楚提示先退网、不自动重连，移除备用订阅不影响当前连接。
6. **套餐与流量**：区分服务端剩余/到期/限速和本机今日/累计/实时上下行；使用真实 null 无限、未知空值和离线状态。短租约时间不能标为套餐到期，保留计量来源说明。
7. **源网选择**：节点使用官方 List/Radio，长名完整可读，不暴露服务器 Endpoint、管理入口、设备密钥、租约ID。不可用节点原因可读且不能选择，刷新失败不保留可点击的过期开始按钮。
8. **退出与恢复**：状态未知、订阅离线时仍能请求退网；保留正在恢复、恢复失败和排队退出提示。退出按钮不藏到折叠区，最小化/关闭语义清楚，关闭仍先恢复网络。
9. **安全和辅助操作**：热点/断开/个人账号/恢复失败事件始终显式显示。手动 Wi-Fi 扫描、接入检查、个人账号先退网和注销留在保护/帮助区域；扫描和检查不能自动切换 Wi-Fi 或启动入网。
10. **通知设置**：保留可持久保存的通知开关。关闭托盘弹窗不等于隐藏客户端安全警告；设置动作不能连接或断开网络。
11. **桌面与可访问性**：580x820 默认原生窗、420x560 最小窗，以及390x844/900x900可读；内容滚动、长值换行、错误完整、可见焦点、输入标签和 Accordion aria-expanded 保持。标题栏不能覆盖状态或主操作，浏览器不显示无效原生窗口按钮。
12. **验证和交付**：所有浏览器请求用 fixture 拦截，不在操作员电脑运行真实客户端或变更网络。核验添加、切换、移除、手动入网、重复点击保护、退出与排队、恢复、通知、安全提示、长值和 CSP；通过后打包普通客户端 EXE/分发包，静态检查制品中的源码和资源一致。不能将模拟验收称作真实校园入网验收。

## 实现前设计系统计划

- 产品语气与密度：简洁中文付费入网工具，中等密度，主连接任务优先。
- 颜色角色：Framework7 iOS 默认背景/表面/文字/弱文字/主操作/成功/警告/危险/焦点，不创建新品牌配色。
- 字号层次：官方 navbar、block-title、list-title、正文和辅助文字，系统字体回退；不使用视口宽度字号。
- 布局与间距：现成 block/list/card 间距，顶端添加订阅，连接区集中，流量与辅助设置分层；不嵌套装饰卡片。
- 圆角边框阴影：官方默认规则，仅克制地适配桌面分区，不自制渐变/阴影主题。
- 组件库存：Navbar、List/Radio、Card、Button、Accordion、Dialog、Toggle 和现有状态/提示组件。
- 状态：未订阅、未入网、正在处理、已入网、离线/未知、恢复中/失败、接入警告、折叠/选中/禁用/焦点。
- 响应式：默认/最小原生窗和窄屏滚动，宽屏可使用组件允许的分栏；重要长值可完整阅读。
- 实现映射：只 client_ui/index.html、client.css、必要的client.js；不改客户网络后端和 Next。父智能体负责测试、制品、文档。

出处与版本以 client_ui 中现有 Framework7 本地资产和第三方声明为准，参考 [Framework7 iOS 组件文档](https://framework7.io/docs/)。
