This panel uses the shipped Framework7 iOS stylesheet unchanged, and adapts these official developed components to local network data:

- https://framework7.io/docs/app-layout
- https://framework7.io/docs/cards
- https://framework7.io/docs/list-view
- https://framework7.io/docs/dialog
- https://framework7.io/docs/button
- https://framework7.io/docs/panel
- https://framework7.io/docs/menu-list
- https://framework7.io/docs/tabs
- https://framework7.io/docs/inputs
- https://framework7.io/docs/area-chart

The 0.3 desktop layout uses the official persistent Panel breakpoint (900px), Menu List selection, Tabs, input lists and Area Chart runtime. Both the JavaScript bundle and styles are locally bundled from the pinned package; there are no CDN requests. The integration stylesheet only handles responsive flow, readable long values, native disabled controls and the native HTML dialog host. Apple trademarks and system fonts are not bundled. This is a third-party iOS-style implementation, not Apple software.
