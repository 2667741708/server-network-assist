              恢复入口

              无法联网时的检查顺序
              1. 检查网卡、出口机和 SSH 连通性。
              2. 直连成功而应用失败时，先检查系统代理与 PAC。
              3. 共享方案异常时，查看错误并执行“断开并恢复原网络”。若恢复未完成，保留方案并重试恢复。
              4. 恢复后重新探测公网和系统应用，不要仅凭隧道显示“已连接”判断成功。
