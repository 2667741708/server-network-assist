03 / SHARED NETWORK

共享网络

先确认出口机与客户端，再查看路径、探测结果和恢复边界。启用 WireGuard 不等于公网一定可用。

启用前看清路径。物理出口方案：Client → WireGuard → Source Host → Internet；源代理方案：Client → WireGuard → Source Proxy。每次启用都会经过后端连通性检查和可回退流程。
