# Security Policy

Please do not report vulnerabilities in public issues. Use GitHub's private security advisory flow for this repository.

Never include real passwords, private keys, recovery keys, cookies, full internal inventories, or unredacted SSH configuration in a report. Include the affected version, impact, minimal reproduction, and a proposed mitigation when possible.

Only the latest release line receives security fixes while the project is in alpha. See [docs/SECURITY.md](docs/SECURITY.md) for the deployment threat model.
